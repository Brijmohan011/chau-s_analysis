06 / THEORY

Model and equations

This virtual lab integrates the dimensionless Chua system with a fourth-order Runge–Kutta (RK4) method. State variables are x, y, z; plotted x and y correspond to scaled capacitor voltages, while z is related to inductor current.

dx/dτ = α [ y − x − h(x) ] dy/dτ = x − y + z dz/dτ = −β y h(x) = m₁x + ½(m₀ − m₁)(|x+1| − |x−1|)

This is a normalized mathematical model, not a hardware-accurate component-level SPICE simulation. For physical circuit design, validate component values and scaling separately.
