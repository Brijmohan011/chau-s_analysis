# CSS – Chua's Circuit Virtual Laboratory

This folder contains the CSS stylesheets used to design and customize the user interface of the **Chua's Circuit Analysis for Electronic Chaos Generation Virtual Lab**.

## Description
The CSS is responsible for creating a modern, responsive, and user-friendly virtual laboratory interface. It provides the visual design for simulation controls, circuit diagrams, waveform graphs, parameter sliders, buttons, and dashboard panels.

## Key Features
- Modern dark blue technology-themed design.
- Responsive layout for different screen sizes.
- Styled simulation control buttons.
- Attractive parameter sliders and input controls.
- Professional dashboard and laboratory panels.
- Custom colors, typography, borders, and spacing.
- Organized layout for waveform and attractor visualization.

## Technologies Used
- CSS3
- Flexbox
- CSS Grid
- Responsive Web Design

## Purpose
To provide an interactive and visually appealing environment for understanding and analyzing Chua's circuit and electronic chaos generation.
