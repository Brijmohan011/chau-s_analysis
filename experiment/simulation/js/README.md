# JavaScript – Chua's Circuit Virtual Laboratory

## Description
This folder contains the JavaScript code responsible for the functionality and simulation logic of the **Chua's Circuit Analysis for Electronic Chaos Generation Virtual Lab**.

JavaScript is used to implement the mathematical model of Chua's circuit, perform numerical calculations, control the simulation, and generate real-time graphical representations of chaotic behaviour.

## Key Features
- Implementation of Chua's circuit differential equations.
- Numerical simulation using the Fourth-Order Runge-Kutta (RK4) method.
- Start, Pause, and Reset simulation controls.
- Dynamic adjustment of circuit parameters.
- Initial condition configuration.
- Real-time waveform generation.
- Phase-plane and Double-Scroll Attractor visualization.
- Simulation data export in CSV format.
- Dynamic graph updates using HTML Canvas.

## Technologies Used
- JavaScript (ES6)
- Mathematical Modeling
- Numerical Analysis (RK4)
- HTML Canvas API
- CSV Data Export

## Purpose
To simulate electronic chaos generation mathematically and provide an interactive environment for analyzing nonlinear dynamic systems.
